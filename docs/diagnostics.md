# 诊断与数据保留

维护权限用户可在设置中选择本地日期范围，导出诊断 ZIP。日期首尾均包含在内；有限保留 N 天包含当天，最早可选日期为当天往前 N−1 天。包包含所选实验的结构化摘要、审计及遥测、登记媒体、原始分析输出（包括可用掩码）、按日诊断日志、系统信息和带 SHA-256 的清单；缺失、校验失败或已按保留策略清理的文件列入清单。包不包含数据库或签署私钥，敏感字段及日志中的常见凭据模式会脱敏。请仍按本单位制度保护诊断包，审阅其内容后再交付。

软件使用 Python 标准 logging：DEBUG、INFO、WARNING、ERROR、CRITICAL；Qt 消息映射到相应等级。日志包含带时区时间、运行标识、线程和 logger，异常包含堆栈。日文件位于数据目录 `diagnostics/logs/YYYY-MM-DD.log`，原有容量轮转日志也保留。

数据保留天数为空或 0 时不自动删除。有限值生效后，后台在启动、配置变化和跨日时检查，并在失败后重试。仅受控目录中的过期诊断日志、可证明已完成且没有任何签署报告的实验原始分析输出与登记媒体可被清理；活动、已签署、未知归属、视频源路径和越界链接受保护。每项清理先记审计，再操作并记录结果；媒体登记及哈希保留。文件在清理意图之后缺失但原因不能确定时标为待核实，不当作已清理。

日志、诊断输出、媒体、数据库及密钥的备份和保留制度仍需现场确认。清理无法撤销，自动测试和模拟设备结果不替代真实仪器、安装、卸载与现场验收。
