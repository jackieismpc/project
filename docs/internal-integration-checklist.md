# 内部接入清单（不随产品界面展示）

本清单记录统一发行入口当前使用的替代实现、边界和后续逐项接入事项。当前软件仅用于流程联调与交互验收；界面和报告不显示实现来源。真实设备、相机、分析算法及外部服务接入完成并验收前，不能将替代结果视为检测结论。

## 当前替代实现及边界

| 接口 | 当前实现 | 边界与证据 |
|---|---|---|
| 账号初始化 | `simulation/demo_accounts.py` 初始化三个受控测试账号；已有数据目录不会覆写账号或密码 | 仅新数据目录使用文档中的测试凭据。现场部署前须确定账号初始化、密码交付和回收方案 |
| 设备 | `simulation/sim_device.py` | 软件内固定设备状态、动作和温度模拟；不连接真实运动控制器、翻转机构、温控器或安全联锁 |
| 视频 | `simulation/sim_video.py`、`simulation/image_synth.py` | 生成可重复的合成画面供流程联调；不采集工业相机，不证明光学质量、帧率或现场照明适用性 |
| 分析 | `simulation/mock_analyzer.py` | 当前默认脚本化模式按固定种子和管位生成状态及特征，结果可重复；没有经确认的真实算法模型、标定数据或药典效能验证。结果不可用于真实检测 |
| 试剂解析、备案和溯源 | `simulation/reagents.py` | 当前按内置样例及名单处理；码格式、名单和政府平台接口均待正式资料与授权 |
| 数据库 | SQLite、当前版本 schema | 开发期直接按当前结构迭代，不为既有开发数据维护迁移兼容承诺。最终交付前需按验收方案重建并清理数据库；本批不清库、不删除现有数据 |
| 报告字体 | Times New Roman（英文/数字）与 SimSun（中文），依赖目标操作系统安装 | 代码设置字体优先级并在渲染时检查；字体是否可用、字形嵌入表现和许可适用范围需在各发布平台确认。未随软件分发这些系统字体 |
| 发行 | `uv run gelinspect` 及 `uv run python scripts/build.py` | 单一正式发行路径；打包包含当前完整流程实现和固定替代后端，不再按正式/演示版分包 |

## 后续逐项接入清单

每项都应先取得接口资料，再实现适配层、补充离线与故障测试、在目标设备上验收，并记录版本、责任方和验收证据。不要用替代实现结果代替验收。

- [ ] **设备控制**：确定控制器型号、通信协议、命令/事件、超时、重试、急停、门禁和故障恢复边界；实现 `DeviceController` 适配器并做硬件联调。
- [ ] **工业相机与视频**：确认相机/镜头/光源、SDK、分辨率、触发与曝光参数、时间同步和存储策略；实现 `VideoSource`，验证掉帧、断流、重连、抓帧与长时录像。
- [ ] **判读算法**：取得正式算法包、模型/阈值版本、训练及验证集、三态判读和异常契约；实现 `GelAnalyzer` 适配器，使用算法契约测试及独立 QA 数据验证准确性、重复性和性能。
- [ ] **试剂溯源**：取得正式编码规范、备案清单来源、鉴权与网络接口及失败处理要求；实现 parser、registry、government client，并验收过期、撤销、不可用和审计路径。
- [ ] **结果与规则确认**：由甲方 QA 确认试验判定规则、结论条件、人工复核、签署及报告字段；形成有版本的批准记录并对历史结果保持可追溯。
- [ ] **账号与现场数据**：确认现场账号名单、权限、初始凭据交付/轮换、数据目录、备份恢复、保留期及清库授权；按验收方案最终重建数据库。此清理当前未执行，现有数据保留。
- [ ] **发布与验收**：在目标 Windows/macOS 环境完成单一路径构建、安装、升级、完整性校验、离线启动、日志收集和备份恢复验证；逐平台留存制品哈希及验收记录。
