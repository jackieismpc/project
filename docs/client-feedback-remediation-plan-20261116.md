## 二、菜单、权限与完整操作流程

### 1. 菜单布局

左侧负责功能页面，顶部保留高频入口、状态和个人设置。

| 位置 | 功能 |
|---|---|
| 左侧 | 工作台、历史记录、模板管理、试剂记录、报告中心、审计追踪 |
| 左侧，管理员及开发人员专属 | 用户管理 |
| 顶部主要入口 | 新建实验、报告中心、当前实验（存在运行中实验时） |
| 顶部右侧 | 设备状态、语言、设置、账号 |
| 设置菜单 | 外观设置、仪器与维护、关于；开发人员另有公司与版权设置 |

- 顶部与左侧“报告中心”名称、图标及目标页面保持一致。
- 原“打开文件”入口删除，历史查询统一称“历史记录”。
- “打印报告”仅作为报告详情中的动作，不再用作报告中心入口名称。
- 实验监控、单管详情、报告详情和模板编辑作为带上下文的页面，不单独占用左侧菜单。
- 现有“试剂溯源”改为“试剂记录”，政府接口待确认，不暗示已完成真实溯源。
- 全面核查侧栏、快捷菜单、子菜单、按钮、标题、快捷键提示及三种语言翻译；统一使用“实验”。
- 窄窗口使用“更多”收纳，保证主要操作及账号入口可用。

历史记录负责全部状态的实验；报告中心负责报告处理，两者保留独立，但复用实验查询和定位能力。

### 2. 三类账号及8组权限

开发人员拥有全部能力，并独占公司、品牌、版权设置。管理员拥有其余全部能力。

| 普通用户权限组 | 包含能力 |
|---|---|
| 查看记录 | 查看实验、结果、视频、模板、试剂记录及报告预览 |
| 实验操作 | 新建、扫码、调整本次配置、启动、停止及异常恢复 |
| 模板管理 | 新建、复制、编辑、另存、删除自建模板，隐藏／恢复内置模板 |
| 结果复核 | 人工复核任意已有结果的管 |
| 报告签署 | 签署报告及修订版 |
| 打印与导出 | 打印、单份／批量报告及实验数据导出 |
| 审计查询 | 查看、查询及导出审计 |
| 仪器与维护 | 仪器、相机、数据设置及诊断包导出 |

- 业务权限自动包含必要的查看能力，授权页面说明依赖；保留只读用户。
- 审计导出归审计查询组，普通打印与导出权限不能读取审计。
- 普通用户默认无业务权限，可自由组合授权。
- 用户管理为管理员和开发人员固定能力，不授权普通用户。
- 用户管理支持创建普通账号、启停、重置密码及授权／撤权。
- 开发账号由我方受控初始化，无通用默认密码；管理员不能创建或修改开发账号。
- 个人外观设置无需授权。
- 服务层统一检查权限，界面同步控制入口，撤权及时影响当前会话。

### 3. 页面关联

- 新建实验支持从模板或空白配置开始，不要求先保存模板。
- 模板管理提供“使用此模板新建实验”，带入配置继续操作。
- 新建实验中有模板管理权限者可“另存为模板”，保存后继续当前草稿。
- 历史记录可进入实验数据或对应报告；实验数据、报告详情均可返回或定位历史记录。
- 报告详情可返回报告列表或查看对应实验数据。
- 单管详情返回原实验及原管位。
- 返回列表保留筛选、排序、页码和选中记录。
- 实验结束后提示查看当前报告；仍待复核时明确显示状态。
- 所有跳转按权限开放，不因页面关联获得额外能力。

## 三、业务修复

### 1. 模板及实验配置

- 模板编辑与新建实验共用试管配置组件和校验规则。
- 启动前可增删试管、修改用途和参数；启动后固定本次配置。
- “删除最后一支”改为“删除选中试管”，支持多选。
- 自建模板可删除，确认框说明影响；删除后不可再用于新实验，保留删除标记和审计。
- 内置模板可隐藏及恢复，不永久删除；修改其副本后可直接运行或另存。
- 模板删除不影响已运行实验的配置快照；已打开草稿提示来源变化，允许有权限者保留本次配置。
- 模板记录创建人、时间、来源和版本。
- 第3步支持序号／管号排序，使用稳定标识关联样品、参数及管位，防止串管。
- 样品批号支持扫码枪连续逐管录入及填入选中多管，保留手工输入。
- 每管λ倍数可调整，按试剂标示灵敏度计算外加内毒素；缺少依据时明确提示。
- 检查空配置、重复管位、最多96管及非法数值。

### 2. 第2步试剂录入：本轮轻量调整

保留现有三张试剂卡，不增加复杂产品档案、检索或审批流程。

- 每张卡提供“扫码／手动录入”切换。
- 扫码接收完整编码；手动录入使用产品编码、批号、有效期等独立字段，种类由卡片自动确定。
- 鲎试剂按需显示标示灵敏度，必填要求由统一校验规则决定。
- 能从可信记录获得的信息自动补全并显示；不推测有效期、不伪造序列号或备案状态。
- 录入时间由系统记录，与有效期分开。
- 扫码和手动输入转换为统一结构，使用同一校验逻辑，不让用户拼接编码。
- 任一字段修改后原通过状态失效，重新校验；创建及启动实验时后台再次检查。
- 手动录入给出缺失字段或未找到记录的具体提示，不统一要求重新扫码。
- 记录录入方式、原始输入及校验结果；演示模式提供方便的示例填充。
- 正式试剂判定接入甲方算法；本轮先改善试用体验，字段和交互待甲方反馈后细化。政府接口继续等待确认。

### 3. 结果、人工复核与报告版本

- 最终结果只有阴阳性；保留待复核、识别异常等处理状态，未明确结果不得签署。
- 任意已有结果的管均可复核，结论不变也记录。
- 保存原算法结果及历次复核结论、人员、时间和必填原因。
- 实验数据、报告和导出逐管强制标注人工复核。
- 已签署实验复核生成修订版，原签署文件保留，新版重新签署。
- 单管详情保留结果、图像／视频证据及复核；三帧默认展开，隐藏掩码及内部算法指标。
- 输出和签署采用操作开始时的客户端语言，移除独立报告语言设置。
- 已签署原件不改写；其他语言的正式版本重新生成并签署。
- 清理重复强调本机签名性质及CA升级的说明，保留签署、验签和必要证书信息。

### 4. 报告中心及打印预览

- 首页展示实验记录列表，点击进入具体报告；批量导出放在列表。
- 按样品及各类试剂批号筛选实验和报告。
- 完整删除单批次汇总报告的界面、路由、接口、汇总逻辑、专属类型／字段、翻译、文档及测试，不保留兼容入口。
- 保留按批号查询及多份独立实验报告批量导出。
- 单独定位修复打印预览缩略图不显示问题。
- 缩略图内容及页数与主预览一致，点击定位对应页；切换报告、语言及修订版后正确刷新。
- 渲染失败提供可重试提示，记录完整错误，不残留旧报告画面。

### 5. 视频联动

按参考图实现：

- 点击Row标题选择整排，右侧切换并播放对应视频。
- 右侧切换Row时，左侧整列绿色边框同步，保留结果颜色和单管详情入口。
- 无视频、文件损坏或快速切换时停止旧播放、清除旧画面并提示。
- 异步加载结果不得覆盖新选中的实验或排。

### 6. 审计、日志及诊断包

- 审计覆盖所有账号的变更、扫码、运行、复核、签署、打印、导入导出、查看查询及视频访问。
- 不逐次记录按键、鼠标、视频帧及自动刷新；草稿按提交、放弃等业务动作记录。
- 数据变更与审计保持一致，记录对象、结果、前后值和失败原因。
- 界面提示简洁、可操作；后台包含稳定错误码、完整原因、上下文及异常堆栈。
- 日志规范归档，默认不自动删除，提供容量提示。
- 诊断包包含相关日志、审计、输入图片／视频、算法输出、参数、复核记录及文件校验清单。
- 打包支持进度和取消，缺失文件明确列出，排除密码、私钥等秘密。

## 四、简约界面、字体与交付

### 1. 界面与字体

- 默认浅色背景、白色内容区、单一主强调色，减少重复卡片、粗重边框及过大标题。
- 统一表格、间距、按钮层级和选中状态，突出当前主要操作。
- 用户可调整主色、背景、内容区、文字颜色及字号，支持预览和恢复默认，按账号保存。
- 结果颜色保持一致，并配文字／形状区分；低对比度配色给出提示。
- 默认使用Noto Sans CJK，内置思源黑体、思源宋体、霞鹜文楷供选择。
- 随包保留字体版权及许可文件，离线可切换；检查简繁字符、符号、缺字回退及切换后布局。
- 报告字体独立固定：中文暂定宋体，英文及数字Times New Roman；发布前确认可用性及合法分发来源。
- 简体、繁体、英文及Windows常见缩放比例均验证，避免文字截断。

### 2. 演示模式

- 演示版作为正式程序的运行模式，共用业务、界面、权限、存储和构建流程。
- 仅集中配置模拟输入、演示标识和必要功能屏蔽，不另写业务实现。
- 演示与正式数据隔离，本轮无设备绑定或有效期。
- Windows安装包包含运行依赖，无需用户配置环境。
- 发布包排除源码工程、开发凭据及签名私钥，保留完整性检查。
- 两种模式均验证共享业务；真实设备及算法按实机证据验收，模拟通过不代替正式验收。
