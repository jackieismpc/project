# 变更日志

本文件记录项目的重要变更，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [未发布]

### 变更

- 新增“通用检测”试验类型和内置模板“通用检测（96 管）”：96 支管都是样品，每管按凝固状态直接给出阴阳性，结论为“不适用”，复核完即可签署。模拟时没有对照的孔板按比例给出阴阳性。
- 演示账号的密码统一为 `12345678`（只影响新建的数据目录）。
- README 写明三种启动方式（演示、模拟运行、正式）和数据存储方式。
- 内置模板按中国药典通则 1143 排布并标明每管用途：灵敏度复核 18 管（阴性对照 2 管）、干扰试验 28 管、限度试验 8 管、复试 10 管、半定量试验 20 管；去掉“布局待确认”标记。新增用途“供试品内毒素系列”。启动时把内容有变化的内置模板更新为程序定义。
- 实现干扰（Es、Et）、限度（含复试）、半定量（终点稀释倍数 × λ 与限值比较）三类试验的判定；试验结论功能默认打开。
- 登录页的演示账号和试剂卡的示例码默认不显示，用启动参数 `--demo` 打开。
- 人工复核的“判为阳性 / 判为阴性”按钮选中后按阴阳性着色，提交后保持显示复核结果。
- 复试并入限度试验：删除“复试试验”类型，改为限度试验下的“限度试验（复试）”模板（中国药典通则 1143 中复试是限度试验一阳一阴后的第二步）。迁移 0006 删除旧的内置复试模板，已有的 `retest` 类型改为 `limit`。
- 单管详情页新增“判读过程”卡片：每项特征的测量值、归一化得分、权重和贡献，评分条标出两条阈值，显示凝固状态到阴阳性的换算；“判读依据”对话框给出药典判读标准、阳性和阴性示例照片、判读步骤和当前映射。质心偏移 Δs 改为显示 3 位小数。
- 算法接口新增两个可选字段：`TubeAnalysis.score_terms`（评分分项，加权和须与 `score` 一致）和 `AnalyzerInfo.thresholds`（三态阈值），随单管结果存档。模拟算法给出这两项，权重、阈值和归一化上限可在 YAML 配置中调整。
- 试剂未通过校验（过期、未备案等）锁定流程时弹窗提示，页面横幅保留；启动前复核发现过期时同样弹窗。
- 逐条审校繁体中文和英文译文：繁体统一台湾用语（數位簽章、憑證、唯讀、新增、重設、導覽、筆）；英文批号统一为 lot，术语改为 Sensitivity confirmation、Positive product control、Water for BET、Endotoxin standard，省略号统一为 “…”。
- 新增繁体中文（台湾用语，zh_TW）界面、PDF 报告和 Excel 导出，三种语言运行中切换。内置字体补入 Big5 一级字和界面、报告实际用到的全部字符，繁体下没有字符回退到系统字体。
- 孔板由 8×10（80 孔）改为 12 排 × 8 支（96 孔）：管号 1～96，第 1 排为 1～8 号，每排从左到右；界面每排一竖列，列头 Row01～Row12。管位常量以 `domain.plate` 为唯一来源。不兼容旧的 80 孔试验。
- 修正监控页第 11、12 排倒计时不刷新；孔板倒计时文字过宽时自动缩小字号；结论中的连续管号合并显示。
- 文档、界面文字、报告模板和注释中的「」统一改为“”，英文翻译同步保留。
- 新增试验结论开关 `conclusions.enabled`，默认关闭：界面、PDF、Excel 不显示结论、λc 和规则版本，签署不再要求入库结论，也不计算、不入库结论。判定规则确认后改为 true 即可打开。

### 修复

- 切换账号（退出登录后再登录）后，试验运行时报“Internal C++ object already deleted”：工作台页面用 lambda 连接引擎信号，页面销毁后不会断开。改为页面自己的槽，销毁时自动断开。
- 报告缺少译文时，警告日志的格式串参数不足，导致签署失败；现在只写警告并回退原文。
- 审计页和历史记录页：翻页期间有新记录写入时后面的页错位、总数和记录不一致。现在每次新查询固定范围，点“查询”或“刷新”才看到新记录。
- 视频管线：状态改为在事件之后发布，看到 `FAILED`、`ENDED`、重连计数或录制段结束的观察者都能读到原因；采集线程意外退出也发 `reconnect_failed`。
- 试验引擎：告警和孔更新先于快照入队；排的截止时间先于 `incubating` 状态设定。
- 试验引擎：写锁被占用时等待（`storage_busy_timeout_s`，默认 60 秒），不再因此中止试验；等待期间不翻转。
- 模拟视频源：`captured_at` 改为场景采样时刻，避免翻转中的帧被当成翻转后的帧。
- 测试：消除固定 sleep 加断言等高负载下脆弱的写法。

### 新增

- P0：工程骨架，包括 uv 项目配置、ruff/mypy/pytest 工具配置、源码分层目录、命令行入口 `gelinspect --version`、冒烟测试与中文文档。
- P1：领域模型（实体、8×10 管位、试验状态机、权限矩阵、五类内置模板、三态映射）；算法、视频、设备、溯源接口契约；三个适配模板；算法契约测试和领域单元测试；架构、算法接口、试验生命周期和权限文档。
- P3：SQLite + SQLAlchemy 数据层、Alembic 迁移（不依赖 alembic.ini）、仓储接口与实现；SHA-256 哈希链审计日志，可定位被篡改或删除的第一条记录；`seed_defaults()` 写入内置模板和首次登录须改密的管理员。
- P4：`simulation/` 模拟数据目录（主代码不导入）：背光试管图合成器、`MockAnalyzer`、`SimDevice`、`SimVideoSource`、试剂白名单和示例数据，支持时间加速和故障注入。
- P2：Qt 设计系统（token、QSS 生成、内置 Noto Sans SC 子集与 IBM Plex Mono、Lucide 图标）和组件库（含 8×10 PlateGrid、TubeStrip、Sparkline）；组件展示页 `python -m gelinspect.ui.gallery`，支持离屏截图。
- 顶部快捷栏 `QuickToolbar`（6 个带权限和键盘快捷键的操作，窄屏收进“更多”）和应用外壳 `AppShell`（侧栏默认自动隐藏，可固定，模式持久化）。
- P5：视频管线：采集线程、带字节上限和 pin 保护的环形缓冲、实时预览、按排分段录制 MP4（SHA-256、丢帧计数）、翻转前后抓帧、黑屏/过曝/卡帧/断流检查和自动重连；输入支持视频文件、图片文件夹和 `load_row_capture`（暂不实现实时摄像头）；中文路径读写。4000×3000、10 fps 压测：约 10 fps，驱动丢帧 0，缓冲 504 MB 封顶，抓拍无丢帧。
- P6：试验引擎：10 排按截止时间调度，串联设备、视频和算法；算法超时只告警，`AnalyzerError` 不打断其他排并可重试；停止、设备故障、视频断流、温度持续越限都有明确行为并写审计；启动时把中断的试验标记为异常。工作单元让试验状态、单管结果、媒体记录和审计同一事务提交。配置按类路径加载后端，默认指向 `simulation/`。`DeviceController` 新增 `select_row`。
- P7：主窗口、登录、锁屏、权限（界面禁用加服务层校验）、简体中文和英文切换；`uv run gelinspect` 一键启动，首次自动初始化 `data/`，默认加载 `simulation/`，启动失败给出说明；退出有序关闭。模拟配置自动创建演示账号，真实配置首次启动创建管理员。其余页面暂为占位。
- P8：新试验向导（选模板、扫码校验试剂、录入样品和管位、确认启动），过期或未备案锁定流程并写审计，服务层再次校验；模板管理页；试剂溯源页（含校验记录和政府溯源入口预留）；试剂校验记录表（迁移 0002）。创建管理员设的密码直接生效；等写锁超时给出可理解的提示。
- P9：试验监控页（实时视频预览、孔板和倒计时、告警横幅、按排回放、停止试验）、单管详情页（翻转前后图、掩码叠加、人工复核）、工作台真实数据、历史记录最小入口。算法掩码存档为 PNG，与结果同一事务入库；最后一管复核完试验转已完成，算法原始结果保留。
- P10：试验结论（合格、不合格、无效、待定）。灵敏度复核按 λc = antilg(mean(lg 终点)) 判定，结论与“已完成”同事务入库，规则变更不改写历史；干扰、复试、半定量、限度在 QA 确认前只给待定。灵敏度模板改存 λ 倍数，创建试验时算出外加内毒素并固化。低置信度阈值可配置（默认不启用）。模拟结果默认符合剂量关系。监控页增加结论卡、恢复试验和重试分析，重启后可离线重试；新增完成时间。迁移 0003。
- P11：报告中心：A4 PDF 报告（中英文）、预览与打印；分析员再次验证密码后签署，生成 PAdES 数字签名并锁定试验；本地自签证书和重新验签（防篡改，无 CA 法律效力）；单批次报告；批量导出和清单。待定或无效的结论禁止签署。迁移 0004。
- P12：历史记录页（筛选、分页、导出）、审计追踪页（查询、后台校验哈希链、导出）、用户与权限页、仪器设置页（视频输入和预览，保存到数据目录的用户配置，审计记旧值和新值）；Excel 导出带公式注入防护；MVD 和内毒素限值录入并显示在报告中；删除占位页。10 万条审计下各页查询均小于 40 ms，导出 1 万管 0.85 秒。
- P13：报告签名私钥加密存储（Windows DPAPI、macOS 钥匙串、安装密钥回退）；审计链改用 HMAC-SHA256 并兼容旧链（迁移 0005）；导出可选 AES-256 加密 ZIP；发布包文件清单签名并在启动时校验；授权接口（默认不启用）。`scripts/build.py` 用 Nuitka 构建目录模式发布包，正式包排除 `simulation/`；GitHub Actions 双平台构建；发布包使用平台标准数据目录。
- P14：用户手册（30 张真实截图）、验收指标报告、交接说明；验收测量脚本；英文界面告警、模板名和标点修正，补全英文翻译；清理开发阶段编号。
