# 应用外壳：顶部快捷栏与自动隐藏侧栏

对应阶段：P2 评审后的框架调整，供 P3 及之后所有页面复用。代码在 `src/gelinspect/ui/widgets/quick_toolbar.py` 与 `app_shell.py`。

## 目的

评审 Qt 组件后提出两点：左侧菜单栏要能自动隐藏，把宽度还给孔板、视频和数据表；窗口上方要有常用操作的快捷入口。

- `QuickToolbar`：全局常驻的顶部快捷栏，放菜单按钮、6 个快捷操作和状态区。
- `AppShell`：把快捷栏、`SideNav` 和页面内容拼成统一外壳，管理侧栏的两种模式。

页面只需要写内容，用 `AppShell(content)` 包起来即可。`monitor_sample.py` 与 `gallery.py` 已接入；P7 起真实主窗口 `ui/main_window.py` 用它承载页面栈，登录、权限、语言见 [auth-and-i18n.md](auth-and-i18n.md)。

## 流程

### 布局

```
┌───────────────────────────────────────────────────────────────┐
│ [≡] │ 新建试验 打开文件 检测模板 打印报告 审计追踪 仪器设置 … 仪器已连接 简体中文 张工·实验员 │  56px，卡片底色 + 底部 1px 线
├────────────┬──────────────────────────────────────────────────┤
│ SideNav    │ 内容区（页面标题行、孔板、视频、表格……）           │
│ 208px      │                                                  │
└────────────┴──────────────────────────────────────────────────┘
```

快捷栏横贯窗口顶部（在内容区上方），侧栏位于快捷栏之下。这样菜单按钮在两种模式下始终可见，覆盖层展开时不会被盖住，切换模式时快捷栏也不会移位。

### 两种侧栏模式

| 模式 | 侧栏占位 | 内容区 | 说明 |
|---|---|---|---|
| 自动隐藏（默认） | 不占 | 全宽，展开时不重排 | 收起时完全不可见（隐藏且禁用）；左边缘留 6px 热区；展开为覆盖层，右侧有渐隐阴影 |
| 固定 | 208px | 宽度减 208px | 与改版前一致 |

模式由 `ShellSettings` 持久化（键 `ui/nav_mode`），默认实现 `QSettingsShellSettings`（组织与应用名均为 GelInspect），测试与截图注入 `MemoryShellSettings`。构造时传 `mode=` 可强制初始模式且不写入。

### 展开与收起（自动隐藏模式）

覆盖层有三个状态：`CLOSED`、`OPEN_HOVER`（悬停展开）、`OPEN_STICKY`（持久展开）。

| 触发 | 条件 | 结果 |
|---|---|---|
| 鼠标进入左边缘热区 | 已收起 | 悬停展开 |
| 点按热区、点工具栏菜单按钮、`Ctrl+B` | 已收起 | 持久展开 |
| 在悬停展开的侧栏内点按 | 悬停展开 | 转为持久展开 |
| 鼠标离开侧栏 | 悬停展开 | 延迟 500ms 后收起；延迟内回到侧栏则取消 |
| 鼠标离开侧栏 | 持久展开 | 不收起 |
| 点击侧栏与菜单按钮之外的任意位置 | 展开中 | 收起（点击照常传给下层控件，不被吞掉） |
| 选中侧栏项（含已选中项） | 展开中 | 发出 `navigationRequested(key)` 并收起 |
| `Esc` | 展开中 | 收起 |
| 再按 `Ctrl+B` 或菜单按钮 | 展开中 | 收起 |
| 品牌行图钉按钮 | 任意 | 切换到固定模式 |

触摸屏没有悬停，菜单按钮和热区点按是主要入口，它们打开的是持久展开，不会因为“鼠标离开”而收起。

### 固定模式下的菜单按钮

固定时菜单按钮的语义是“取消固定，改为自动隐藏”：点击或按 `Ctrl+B` 后侧栏收起，内容区变宽，模式保存为自动隐藏。按钮提示随状态变化（“展开侧栏”“收起侧栏”“取消固定，侧栏改为自动隐藏”），并附平台格式的 `Ctrl+B`。品牌行图钉按钮显示动作而非状态：自动隐藏时是 `pin`（固定侧栏），固定时是 `pin-off`（取消固定侧栏），无障碍名称同步变化。

### 动画与焦点

- 滑入滑出用 `QPropertyAnimation`，180ms，`OutCubic`。`animations_enabled=False` 关闭，测试与离屏截图使用。
- 收起后侧栏 `setVisible(False)` 且 `setEnabled(False)`，其中的控件既不显示也无法获得焦点，Tab 不会进入。
- 用 `Ctrl+B` 或键盘聚焦的菜单按钮展开时，焦点移到当前选中项；收起时若焦点在侧栏内，归还给展开前的控件，没有则给菜单按钮。鼠标悬停展开不抢焦点。
- 窗口缩放时，覆盖层和热区高度跟随，内容区随宽度变化。

### 快捷栏

从左到右：菜单按钮、竖线、快捷操作（图标加文字）、“更多”（仅在需要时出现）、弹性空白、状态区（仪器连接、语言、当前用户）。

- 快捷操作用 `QuickAction`（id、文字、图标、快捷键、所需 `Permission`）声明式定义，见 `DEFAULT_ACTIONS`。每项对应一个 `QAction` 和一个 `QShortcut`（窗口范围）。触发时发 `actionTriggered(str)`。
- 快捷键写 `QKeySequence.StandardKey`（新建、打开、打印）或可移植字符串（`Ctrl+T`），macOS 上 `Ctrl` 自动对应 Cmd。提示文字用平台本地格式（macOS 为 `⌘N`，其他为 `Ctrl+N`）。
- 宽度不足时从右端开始收进“更多”菜单，按钮文字不截断、控件不越界；被收纳操作的快捷键仍然有效。1280 宽全部显示，1024 宽约收起 2 项，800 宽收起 4 项。
- 状态区：仪器连接用图标加文字区分（`plug` 加“仪器已连接”/`unplug` 加“仪器未连接”），不只靠颜色。P7 起语言和用户是带菜单的按钮：语言菜单（`set_language_options`，选项用各语言自己的名字，发 `languageSelected(code)`）、用户菜单（修改密码、锁定屏幕、退出登录，发 `userActionRequested(id)`；未登录时禁用）。
- 危险操作（停止试验）不放进全局快捷栏，留在页面标题行。
- 文字用 `self.tr()`，上下文为 `QuickToolbar`，操作名用 `QT_TRANSLATE_NOOP` 标记。语言切换时 `changeEvent(LanguageChange)` 调用 `_retranslate_static`，刷新全部文字、提示和无障碍名称。英文下“仪器设置”写成 `Settings`、连接状态写成 `Connected`/`Disconnected`，保证 1280 宽仍能容纳全部 6 个操作。

快捷键表：

| 操作 id | 文字 | 快捷键 | 所需权限 | 允许的角色 |
|---|---|---|---|---|
| `new_experiment` | 新建试验 | `Ctrl+N` | `EXPERIMENT_CREATE` | 实验员 |
| `open_file` | 打开文件 | `Ctrl+O` | `EXPERIMENT_VIEW` | 全部 |
| `templates` | 检测模板 | `Ctrl+T` | `TEMPLATE_VIEW` | 全部 |
| `print_report` | 打印报告 | `Ctrl+P` | `REPORT_VIEW` | 全部 |
| `audit_trail` | 审计追踪 | `Ctrl+L` | `AUDIT_VIEW` | 管理员、分析员 |
| `instrument_settings` | 仪器设置 | `Ctrl+,` | `INSTRUMENT_CONFIGURE` | 管理员 |
| （外壳） | 展开/收起侧栏 | `Ctrl+B` | 无 | 全部 |
| （外壳） | 收起侧栏 | `Esc` | 无 | 全部 |

## 权限

快捷栏自己不判断角色，调用方在登录后调用 `set_user_permissions(permissions_of(role))`（主窗口用 `session.permissions()`，锁屏或必须改密时为空）。创建后默认没有任何权限（默认拒绝）。侧栏同理：`SideNav.set_denied(keys)` 把无权进入的项置灰并禁用，提示“当前角色无此权限”。侧栏在 P7 增加了“关于”项（共 11 项）。

- 无权限的操作：按钮与“更多”菜单项禁用，快捷键不触发，提示显示“某操作：当前角色无此权限”。
- 角色与权限的对应以 `domain/permissions.py` 的 `PERMISSION_ROLES` 为准，见 [permissions.md](permissions.md)。
- 界面隐藏只是体验层，业务层仍须在服务里再次校验权限。

## 数据

- 持久化：`QSettings("GelInspect", "GelInspect")` 的键 `ui/nav_mode`，值为 `auto` 或 `pinned`。不涉及数据库，也没有审计事件。
- 新增图标（Lucide，ISC，按官方路径手写）：`menu`、`pin`、`pin-off`、`folder-open`、`plug`、`unplug`、`languages`、`ellipsis`；P7 增加 `lock`、`log-out`、`key-round`、`construction`。
- 颜色全部来自 token，QSS 角色见 `theme/stylesheet.py`。
