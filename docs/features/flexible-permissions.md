# 三类账号与六组授权

## 目的

甲方反馈第3项：开发数据重置后使用“开发人员／管理员／普通用户”，普通用户按业务组组合授权。2026-11-17按最新反馈把实验操作、结果复核和报告签署合并为“实验与结果处理”组；底层复核及签署权限检查仍保留。

## 流程

管理员和开发人员可以进入“用户管理”；普通用户即使获得全部业务组也不显示此菜单，直接进入或调用管理服务同样拒绝。

- 新建普通用户可同时选择六组权限，默认全部不选；创建后显示一次临时密码，首次登录必须修改。
- “授予／剥夺权限”整组保存，失败保留选择；重复保存相同授权不产生重复变更审计。
- 可启用／停用、重置普通用户密码；停用和重置使其旧会话失效，不能停用自己。
- 开发人员还可创建管理员、启停或重置其他管理员；最后一个启用管理员不能停用或降级。
- 开发账号不提供默认账号密码，不能从普通账号管理接口创建，也不能由管理员修改。开发方使用独立工具受控初始化。
- 授权变更与审计在同一数据库事务提交，写审计失败则授权不变；事务取得写锁后再次确认操作者仍有管理资格。

## 权限

| 组 | 能力与必要依赖 |
|---|---|
| 查看记录 | 查看实验、结果及视频、模板、试剂记录和报告；不含打印或导出 |
| 实验与结果处理 | 上述查看能力、试剂录入校验、新建配置、启动、停止和异常恢复，以及任意已有结果的人工复核、报告及修订版签署 |
| 模板管理 | 查看及管理共享模板；删除／隐藏等具体动作仍按专项后续阶段实现 |
| 打印与导出 | 查看实验与报告、打印和实验数据／报告导出，不包含审计导出 |
| 审计查询 | 查询、校验及导出审计，不要求额外勾选普通数据导出 |
| 仪器与维护 | 仪器／相机／数据设置；诊断包导出能力已预留，具体功能在后续阶段实现 |

开发人员具有全部权限；管理员具有除公司与版权设置之外的全部权限。维护用户及管理员不能修改版权名称，服务层和输入框均限制；开发账号可以设置。

服务每次读取最新账号信息，不信任界面缓存或调用者修改的账号快照。界面每500毫秒同步授权，变化后关闭旧对话框、清除旧页面并回工作台；失效会话返回登录。打开新页面时也重新检查。报告预览可使用 Qt 记录型预览设备；服务向实际打印设备或 PDF 设备绘制前必须重新校验打印权限。报告导出另校验数据导出权限。

撤权只禁止后续受限操作，不自动中断已运行实验；有权限的管理员仍可接管。锁屏、首次改密和注销状态不授予业务能力。

## 数据及开发重置

- `users.role` 只存三类账号；`permission_groups` 为六组标识的JSON数组。
- `auth_version` 在密码变化时递增，使其他登录实例的旧会话也失效；密码更新带预期版本，防止并发旧请求覆盖重置结果。
- 登录验证完成后再次确认凭据未发生变化；权限更新不改变运行中实验的执行身份快照。
- 本轮删除项目内旧 `data/`、`data-formal/` 运行数据及被Git跟踪的正式模式开发数据库／日志；原始素材和代码保留。
- 新版本直接使用新的初始化结构，不迁移旧开发数据。打开旧结构时明确拒绝，既不静默补字段，也不删除用户提供的旧目录。
- 没有清理项目外的安装版数据目录。新运行会生成新的初始化及审计记录，不保留历史实验。

### 开发账号受控初始化

先关闭软件，在开发方受控环境运行：

```bash
uv run python scripts/provision_developer.py --data-dir /absolute/path/to/data
```

工具交互输入并确认密码，不通过参数、环境变量或日志传递密码；不自动覆盖已有开发账号。该脚本不作为普通用户界面入口。新目录只创建开发账号时，由其登录用户管理创建管理员。

模拟配置仍提供原来的三个演示登录名，便于继续验证：`admin` 是管理员；`experimenter`、`analyst` 都是带明确初始授权的普通用户，并非旧角色兼容。演示配置不会生成开发账号；正式配置无演示账号。

## 测试

- 穷举六组的64种组合，普通用户任何组合都不能管理账号或配置公司版权。
- 不含“实验与结果处理”组的普通用户不能复核结果、启动实验或签署报告；原有低权限拒绝覆盖仍保留。
- 验证每组授权、撤权、重新登录及持久化；授权不变时不重复留痕。
- 验证直接服务调用、伪造快照、无权限菜单、已打开页面／对话框撤权，以及账号停用、锁屏、重置和退出。
- 验证跨认证实例密码失效、登录时重置、并发改密与重置版本冲突，避免旧密码请求覆盖新凭据。
- 验证审计写入失败回滚、等待写锁期间管理资格变化、最后管理员和开发账号保护。
- 只读报告直接调用打印也不能生成PDF；数据输出组不获得审计导出能力。
- 用真实模拟引擎确认撤权不停止已运行实验，撤权用户无法停止，管理员可以停止。
- 验证无默认开发密码、初始化工具不覆盖、旧结构明确拒绝且保持原文件。

## 用户验收

1. 重启开发版，用管理员打开“用户管理”；创建普通用户，勾选实验与结果处理、模板管理。
2. 用新账号改密后登录，检查配置、运行、复核及签署能力；“用户管理”不显示。
3. 管理员为其撤销实验与结果处理，确认复核、运行和签署服务操作被拒绝，其余授权保留。
4. 仅授予查看记录，确认可预览，不能打印、导出、新建或签署。
5. 停用或重置已登录账号，确认旧会话回登录；重新启用不会恢复旧会话。
6. 管理员可以运行实验，但不能编辑版权名称；开发账号可操作该字段。
