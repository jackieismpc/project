# 模板删除、隐藏与恢复

模板管理权限由服务层再次校验。自建模板删除采用软删除，数据库保留删除时间和操作者，审计链追加 `template_changed` 事件；已删除模板不进入列表、不能复制或用于新实验。内置模板只允许隐藏和恢复，隐藏状态不会被内置模板启动种子覆盖，隐藏模板不再出现在新实验可选项。

模板表增加 `hidden`、`deleted_at`、`deleted_by`，由数据库迁移 `0007` 创建。实验表保存独立模板配置快照且没有模板外键，删除模板不会改写既有实验。

模板管理页中选中内置模板后可隐藏或恢复；选中自建模板后可执行软删除，确认文字说明其对新实验及历史快照的影响。恢复操作只对具有模板管理权限的用户显示隐藏模板。新实验草稿打开期间若模板来源消失，会提示是否保留原配置快照；服务层仅允许有模板管理权限的会话通过匹配的原模板 ID 提交该快照。

验证状态：模板服务、模板管理界面和数据库迁移定向测试 67 项通过；新增的删除后快照权限与撤权测试 2 项通过。`ruff check`、目标文件格式检查、9 个源文件的 mypy 和三语翻译检查通过。

Windows 实验向导启动测试单独运行时断言通过，但进程同时输出原生异常 `0x80040155`，堆栈位于模拟视频线程 `simulation/image_synth.py:add_noise`。该运行未作为无异常的通过结果；需后续定位/复测。功能仍待用户操作验收。

## 用户验收步骤

1. 使用有模板管理权限的账号打开“模板管理”，隐藏一个内置模板。确认它标记为已隐藏且不再出现在新建实验模板选项中；回到模板管理恢复它，再确认新建实验中重新出现。
2. 创建一个自建模板并确认删除。确认它不能再复制或用于新实验；打开一个此前已创建的实验，核对实验的类型、样品和管位仍与原配置相同。
3. 打开新建实验草稿并选择一个模板；由另一有权限会话隐藏该内置模板或删除该自建模板。回到草稿确认出现来源变化提示；选择保留后继续创建，核对本次配置和管位无变化。再次验证撤销模板管理权限的会话不能通过旧快照继续创建。
4. 编辑自建模板，分别选择中间几行、首尾多行删除；确认只删除所选试管并且至少保留一支。清空选择后删除按钮应不可用；只剩一支时无法继续删除。

首次定向测试曾发现三项断言问题：模板审计基数包含种子初始化事件、编辑器多选后按钮状态未及时刷新，以及旧测试仍假设未选中时删除最后一支。均已修正并更新对应测试。上述自动化结果不替代用户操作验收。
