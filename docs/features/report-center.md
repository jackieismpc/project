# 报告中心

报告中心首页列出可查看的实验及各自的独立报告。用户可按样品批号和鲎试剂、缓冲液、内毒素试剂批号筛选，选择一行打开对应实验报告，也可多选已签署报告批量导出。

首页支持导入任意外部 PDF。系统验证 PDF 数字签名，并核对签名中的报告标识、内容摘要和证书指纹，以关联数据库中的确切报告记录；有效且匹配时显示对应实验报告的打开入口。未签名、未知签署者、无效签名、外部签名或损坏文件会明确说明，未知或损坏文件不标为可信。导入文件内的元数据不覆盖数据库记录。文件无法识别或校验失败时，提示用户检查文件权限并联系后台检查。

报告详情沿用独立实验报告的预览、签署、验签、打印和单份导出流程。批号查询只用于筛选实验，不生成或提供单批次汇总报告。

## 操作

1. 在首页输入或选择样品批号、试剂批号筛选列表。
2. 双击实验行打开其报告；从详情返回后保留原有筛选。
3. 勾选多份已签署报告，点击“批量导出”。
4. 点击“导入外部 PDF”选择文件，查看数字签名状态；仅对签名有效且精确匹配数据库报告的文件提供打开实验报告的入口。
