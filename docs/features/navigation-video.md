# 实验导航与视频联动

历史记录保留查询条件、页码和选中行，打开实验或报告后返回可继续原来的查询。历史列表可分别打开实验回看或对应报告；报告详情提供“查看实验数据”，监控页提供“在报告中心打开”。单管详情返回后恢复对应实验和原管位焦点。

监控页点击孔板上方的 Row 标题时，该排整列显示绿色边框，右侧切换到该排录像并播放。没有录像、录像损坏或快速切换时，播放器停止旧片、清除旧画面并显示说明。实时视频断流、卡住、重连时同样清除最后一帧；恢复后显示新帧。

引擎首次显式打开实验时写一条查看审计；页面轮询、刷新和打开实验详情时不会反复写查看审计。试验进入待复核时提示待处理数量；试验完成时提示可查看报告。
