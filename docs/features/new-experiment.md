# 新试验流程、模板管理与试剂溯源

## 第7项补充：样品排序、批号扫码与 λ 倍数

第 3 步样品行具有稳定标识；表头可按样品名称、批号、λ 倍数或管号排序，排序移动整行，管位和该行样品、用途及参数保持绑定。样品批号输入框可接收键盘楔式扫码枪连续扫码：显式选择多行时把本次码填入所有选中行；没有多选时仅填当前行并将光标移到下一行，支持连续逐管录入。仍可直接逐行手工编辑批号。

每管 λ 倍数可在表格调整，外加内毒素按该管倍数与已校验鲎试剂标示灵敏度计算并显示。缺少有效灵敏度时明确提示，服务端校验覆盖倍数为有限非负值，并在创建时依据可信试剂灵敏度计算外加内毒素，不信任客户端传来的浓度。空模板、重复或越界管位、超 96 管、负数及非有限数值由现有配置和试验服务校验。

本项新增的自动化验证及 Windows 原生界面验证结果记录于 remediation plan。

## 第6项补充：试剂扫码与手动录入

向导第 2 步仍为鲎试剂、内毒素、检查用水三张卡。每卡可切换扫码或手动录入：扫码保留完整条码原文；手动字段分别采集产品编码、批号及可选有效期，卡片自动确定种类。有效期空缺时只由备案记录补齐，不从日期、批号或系统当前时间推测；鲎试剂灵敏度只读显示备案服务返回值，用户不能自行覆盖。演示配置继续提供示例码，一键填入并校验。

两种方式都归一为 `ReagentCode`，使用同一解析／备案结果规则；手动必填字段和日期格式错误给出具体字段提示。卡片输入一旦变动就清除通过结果和草稿中的已校验输入，需重新校验。创建及启动仍由服务层重新检查；校验审计及批次记录保存输入方式和原文，校验时间由系统写入 `checked_at`，不与试剂有效期混用。数据库迁移 `0008` 为历史记录设置扫码默认值。

当前模拟备案只接受内置演示白名单，真实试剂码格式、正式判定算法和政府接口仍待甲方提供；通过模拟清单不构成正式试剂认证。

本项定向验证：试剂服务、实验服务、试剂存储及手动录入和试剂变更失效的向导用例共 53 项通过。覆盖手动录入创建后后台复核并启动、备案信息补全、输入方式与原始字段记录、必填字段提示、修改字段后必须重验，以及绕过界面时服务层仍复核。目标文件 ruff 与格式检查通过，9 个目标源文件 mypy 通过，三语翻译检查通过。初次混合 UI 运行重现 Windows 模拟视频线程 `0x80040155`（`simulation/image_synth.py:add_noise`）；后续两项关键 UI 用例隔离运行通过，异常运行不计入无异常通过。本项代码已完成，等待用户验收。

## 用户验收步骤（第6项）

1. 进入新建实验第 2 步，确认鲎试剂、内毒素、检查用水三张卡仍在，分别切换扫码和手动录入；手动模式显示产品编码、批号、有效期独立输入，鲎试剂灵敏度为只读。
2. 在演示模式选择示例码，确认可一键填入并校验。改动任一卡片字段后，原“已通过”状态应立即清除，下一步禁用，重新校验后才恢复。
3. 手动输入缺少产品编码或批号的记录，确认提示具体缺失字段；输入无效日期格式，确认提示有效期格式。录入白名单产品编码和批号但不填效期时，确认有效期及鲎试剂灵敏度只从备案记录补齐；未知批次显示未备案，不得假定合格。
4. 通过扫码和手动分别校验后查看审计／试剂记录，核对录入方式、原始输入、校验结论和系统校验时间。检查扫码原文保留空白及完整内容；手动数据以独立字段记录，不要求用户拼接试剂码。
5. 完成实验创建和启动；后台应再次校验当前试剂并按已保存的批次再次复核启动条件。使用已过期或未备案批次时应给出具体原因并拒绝启动。

## 第5项补充：模板与单次实验共用配置

新建实验可直接选择模板或从空白配置开始。两种入口共用模板试管编辑器，可在启动前添加／删除试管并调整用途、稀释倍数、外加内毒素和 λ 倍数；最少 1 支、最多 96 支。修改本次配置会提示清空样品及管位输入，同时保留已校验试剂；试管配置按编辑器行序生成稳定管号，样品行与升序选中管位一一对应。

模板管理中的“使用此模板新建实验”会带入模板配置。拥有模板管理权限的用户可在新建实验的样品步骤另存为模板；另存成功不替换或清空当前草稿。单次配置以 `draft.*` 标识及请求快照提交，不写入模板库。服务层统一调用配置构建校验，并在创建时复核试剂、权限、数量、管号及数值；若本次配置来源模板期间被隐藏／删除，只有当前仍有模板管理权限的会话可继续使用该快照。启动后，实验记录保存配置快照，不再随模板变化。

本项自动化状态：服务、草稿及模板管理定向测试 51 项通过；新增空白配置、重复编辑来源保留、另存取消／保存保留草稿 UI 测试 3 项通过。合并相关范围测试 75 项通过、1 项排除。目标 7 个源文件 mypy、相关文件 ruff 和三语翻译检查通过。

Windows 模拟 UI 综合测试出现原生异常 `0x80040155`，线程堆栈指向 `simulation/image_synth.py:add_noise`，与既有记录一致；该次不记为无异常通过。新增加的 3 项交互测试单独运行未出现该异常。功能仍待用户验收。

## 用户验收步骤（第5项）

1. 以只有“实验与结果处理”权限的用户打开新建实验，选择“从空白配置开始”，确认无需先保存模板；在共用编辑器增删试管、调整用途和参数，试管数可为 1–96，移除最后一支或超出96支不可提交。
2. 从模板管理选择一个模板，确认进入向导并带入配置；返回编辑本次配置、选择管位并填写样品，再打开编辑器，确认提示清空样品／管位并保留已校验试剂，取消则配置和样品不变。
3. 以有模板管理权限的用户在新建实验中另存当前配置。分别取消和保存：取消不改变草稿；保存后继续当前草稿，修改过的样品名称、用途及参数保持，模板管理列表出现新模板。
4. 另存模板后撤销当前会话的模板管理权限，再删除或隐藏来源模板。尝试提交已打开草稿，服务端应拒绝；恢复来源模板后，确认配置管位、样品及用途参数关联未串管。
5. 启动实验后核对记录中的管位、样品、用途和参数快照；再编辑／隐藏／删除来源模板，确认已启动实验不变。

对应阶段：P8。代码：`ui/pages/new_experiment.py`、`wizard_widgets.py`、`templates_page.py`、`template_editor.py`、`reagents_page.py`；`services/experiment_service.py`、`experiment_draft.py`、`template_service.py`、`reagent_service.py`、`errors.py`。视觉对照 `docs/design/Wizard.dc.html`。

## 目的

让有“实验与结果处理”权限的用户从选模板到启动试验走完一条不会放行不合格试剂的路径；获“模板管理”组授权者维护检测模板；有查看权限的用户能查试剂批次和校验记录。判定规则（P10）不在本阶段；启动后跳到试验监控页（P9，见 [monitor-and-review.md](monitor-and-review.md)）。

## 流程

### 新试验向导（四步）

1. **选模板**：列出内置和自定义模板（类型、管数）；布局为推定的模板带“布局待确认”徽标，仍可使用。
2. **校验试剂**：鲎试剂、内毒素、检查用水三张卡。扫码枪是键盘楔式，输入框回车即触发，也可手输；示例码（仅模拟配置提供）点一下填入。结果由 `interfaces/traceability.py` 的解析器和备案清单给出。过期、未备案、有效期未知、清单不可用、没有配置，都**锁定流程**：红色横幅写明原因，“下一步”禁用，每次扫码写审计（`reagent_checked`）。种类放错、读不出码只提示重扫，不锁定。
3. **录入样品和管位**：左表（序号、样品名称、样品批号、外加内毒素、管号，可编辑；按 λ 倍数的外加内毒素由鲎试剂的 λ 算出，不能手工改），右侧 `PlateGrid` 选择模式。自动选择选模板默认管号，全部清除清空；显示“已选 n / N · 管位已对应 / 还差 n 个 / 多选了 n 个”。数量不符或样品名称为空不能下一步。模板需要 λ（灵敏度复核或有 λ 倍数）而鲎试剂没有时，第 2 步就不能继续，服务层也拒绝。选中的管号升序后依次对应样品行。
4. **确认启动**：汇总后点“确认并启动”。服务创建试验（就绪）并交给引擎；引擎启动前检查失败（温度越限、舱门、视频等）时横幅显示引擎给出的原因，试验仍为就绪，可“重试启动”（不会再建第二个试验）。启动成功（引擎进入孵育）后向导复位并跳到试验监控页。

返回上一步不丢数据；回到第 3 步时，已为失败启动创建的就绪试验会被放弃（状态 `stopped`，写审计），按新内容重建。离开未完成的向导（导航、快捷栏、退出登录）要确认。更换模板若已录入样品或管位也要确认。

### 服务层再校验

界面被绕过也不放行，`ExperimentService`：

* `create_experiment`：只信任扫码**原文**，自己解析、查备案、按当天日期判断；任一试剂不合格写审计并抛 `ReagentLockedError`，不保存试验。同时校验模板存在、样品数与模板一致、管号合法不重复、样品名称非空。成功时试验经状态机到就绪，创建、试剂校验、状态变化和校验记录在同一事务提交。
* `start_experiment`：对保存的批次按今天复核；过期（隔夜才启动）转 `reagent_locked` 并拒绝。再交给 `ExperimentEngine.start`（它仍校验就绪状态和权限）。
* `abandon_experiment`：放弃就绪但未启动的试验。

### 模板管理

列表加管位详情。内置模板只读，可复制；管理员可新建、复制（得到“X 副本”，可再编辑）、编辑自定义模板：名称、类型、每管的样品名、稀释倍数、外加内毒素（绝对值）、λ 倍数（填了以它为准）、用途。管号按行顺序从 1 编。自定义模板不带“布局待确认”标记。名称不能为空、不能重名（含与内置同名），1 到 96 管。

### 试剂溯源

* 已录入批次：同一种类同一批号取最近一次校验；过期整行红色并写“已过期”，剩余 30 天内黄色“即将到期”，未备案红色；显示剩余天数。
* 校验记录：每次向导里的扫码（有校验结论的）一行，最新在前。
* 扫码查询：所有角色可用，只校验、不写记录。
* 政府溯源码：按 `interfaces/traceability.py` 预留入口，标“接入预留”，输入和按钮禁用，说明状态。

### 配置

`traceability`（`services/config.py`）配置解析器、备案清单、政府溯源客户端的类路径，默认配置指向 `simulation/reagents.py`；真实配置不写时试剂无法校验，向导停在第 2 步说明原因，不会放行。`instrument_no` 写入新试验（默认 `GI-001`）。
