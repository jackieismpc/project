# 非阻塞提示的生命周期与稳定性

## 目的

修复提示自动消失后再次显示提示导致的原生崩溃，覆盖模板保存、复制及其他使用 Toast 的页面。

## 流程

同一窗口只显示一条提示。新提示替换旧提示；关闭提示时停止计时器、移除窗口事件过滤器、清除当前引用，再安排 Qt 延迟销毁。

窗口通过 Python 属性持有当前提示，不使用 QObject 动态属性保存 QObject 指针。访问旧提示前检查 Shiboken 包装对象的原生有效性，兼容外部直接销毁。

## 权限

提示组件不改变授权。模板保存仍由原服务层检查权限。

## 数据

不修改业务数据结构，不清理运行数据，不改变审计及模板规则。

## 测试与证据

- 2026-11-16 系统崩溃记录显示 SIGSEGV，原生栈包含 `QObject::property`、`PySide::getWrapperForQObject` 和 `QVariant_CppToPython_QVariant`。

- 本修复确认消除这条可复现崩溃路径，其他未复现崩溃仍需按实际证据继续排查。

## 用户验证

1. 使用管理员进入模板管理，新建有效模板并保存。
2. 等待保存提示自动消失，再新建并保存另一模板，重复至少5次。
3. 复制模板、编辑并保存，分别在提示消失前后继续操作。
4. 输入空名称或重复名称，确认显示校验提示且能修改后重试；取消后可重新打开。
5. 预期：不闪退；保存结果及审计正确；失败校验不关闭编辑器。
