# 设置与启动路径维护

常规设置（仪器编号、试验参数、温度、视频输入、保留策略、版权方和导出加密）仍由设置服务校验并持久化到当前数据目录的 `user_settings.json`。影响运行的参数在试验运行时由服务端拒绝修改。

“启动配置与数据目录”由 `instrument_configure`（仪器与维护组）权限保护，服务端再次校验权限；界面置灰不是唯一控制。维护人员只能通过文件/目录选择器选择完整 YAML 配置、现有数据目录和可选算法适配配置文件，界面不提供模块名、类名或代码输入。YAML 用安全加载及完整配置 schema 校验，算法类仍由已有启动后端工厂根据配置导入。

启动路径存放在稳定的应用运行选择文件中，不放在可切换的数据根目录里。保存采用同目录临时文件、fsync 和原子替换，并写审计；审计失败时恢复原文件。试验运行中服务拒绝切换。配置路径、数据目录和算法适配配置在下次启动生效；命令行及 `GELINSPECT_DATA_DIR` 显式覆盖 UI 选择。损坏或失效的选择记录会忽略并回到默认启动路径。切换数据目录不会复制、迁移或删除任何数据，旧数据目录保持原样。

算法后端信息卡已从设置页移除，为运行配置和数据目录控制留出空间。此页面文案翻译由 `translations/` 维护。
