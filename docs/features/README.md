# 功能文档模板

每个功能在 `docs/features/` 下建立一篇独立文档，文件名使用小写英文与连字符，例如 `plate-experiment.md`。文档统一包含以下五个部分。

## 目的

说明该功能解决什么问题、面向哪些用户、与哪个阶段对应。

## 流程

使用文字或简单图示描述主要步骤、分支与异常处理。涉及状态变化时，列出状态及迁移条件。

## 权限

列出各角色（如操作员、复核员、管理员）在该功能中的可用操作。

## 数据

列出读写的实体与字段、存储位置（数据库表或文件路径），以及审计日志要记录的事件。

## 测试

列出自动化测试文件、覆盖的场景，以及需要人工验证的项目（例如界面截图检查、Windows 实机验证）。

---

> 模板仅供参考，各功能文档可根据实际内容增减小节，但应保留五个主题。
