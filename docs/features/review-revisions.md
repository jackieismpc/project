# 单管人工复核与签署修订版

## 行为

- 有“实验与结果处理”权限的用户可以复核已生成结果的任意管，包括其他管仍在分析、实验已完成和已签署的实验；没有结果的管不允许复核。
- 每次复核都要选择阳性或阴性并填写原因；结论没有变化也会追加复核历史和审计事件。
- 算法原始结果保留，当前最终结论按最新人工复核结论展示。每条复核历史保留结论、账号、时间和原因，数据库升级会把旧的最新复核字段纳入历史。
- 已签署实验接受复核后仍保持“已签署”状态，原签署PDF不修改。新的签署必须晚于复核时间，生成递增版本的新PDF，并在报告记录中引用被替代的报告记录。
- 报告列表、详情、实验数据导出均按管标注“已复核”；报告结果标注以人工结论为准。
- 外部PDF校验先验证PAdES数字签名，再用签名内的报告标识、实验标识、内容摘要和证书指纹查找本机报告版本。文件SHA-256只是附加信息，不作为报告关联依据。有效但不属于本机报告的文件显示为外部签名文件。

## 权限

复核和签署均在服务端检查“实验与结果处理”能力。查看外部PDF签名和报告记录需要报告查看权限。界面会话撤权后，再次调用服务时拒绝操作。

## 单管详情与报告语言

- 单管详情默认展开翻转前后各3帧；默认不显示算法掩码、融合评分、评分分项、阈值、特征指标、模型和配置版本。异常原因和最终阴阳性保留。
- 报告输出和签署使用点击操作时捕获的客户端语言，不提供独立的报告语言选择。已签署原件保留；切换客户端语言后签署会生成新的递增版本，并引用前一版记录。预览当前语言与最近已签署语言不同时显示新版可签署。
