# 内部账号初始化与权限说明

本文供维护人员使用，不属于用户手册或公开权限说明。内部维护账号不出现在普通账号管理列表，也不能由用户管理服务查询或修改。

## 初始化

先关闭软件，在受控环境运行：

```bash
uv run python scripts/provision_developer.py --data-dir /absolute/path/to/data
```

工具交互输入并确认密码，不通过参数、环境变量或日志传递密码；不自动覆盖已有维护账号。该账号没有默认密码。新目录只创建维护账号时，由其登录后创建管理员。

## 保留能力

内部维护身份保留完整权限，包括公司与版权设置，以及创建、停用、重置或调整管理员的受控管理操作。初始化安全约束不变。审计事件继续记录真实操作者用户名和当时角色，历史记录不匿名化、不改写；面向用户显示时不得用角色标签暴露该内部身份。
